# Weather-app

Overview: This is a simple weather app that allows users to check the weather conditions for a specific location. It is built using HTML, CSS, and JavaScript and makes use of a weather API to fetch real-time weather data.

Features: Display current weather conditions including temperature, humidity, wind speed, and description. Search for weather by city or location. Responsive design for mobile and desktop.

Usage Enter the name of a city or location in the search bar. Click the "Search" button or press Enter. The app will display the current weather conditions for the specified location.

API: Here we use current weather data API from the website open weather map.
